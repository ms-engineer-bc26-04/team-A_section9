## Redis確認方法

`GET /api/v1/schools` を複数回実行し、Render Logs に以下が出力されることを確認する。

```text
"msg":"schools cache hit"
"cacheKey":"schools:list"
```

## 注意点
- Render Freeプランのため、一定時間アクセスがないとスリープする
- 初回アクセス時に起動まで時間がかかる場合がある
- 環境変数の実値はREADME・docs・Issueに記載しない
- REDIS_URL はUpstash RedisのRead/Write用URLを設定する
