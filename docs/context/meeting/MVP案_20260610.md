# ENKATSU MVP案

## 〜園活を円滑に〜

# 1. サービス概要

ENKATSUは、共働き家庭・仕事復帰を控えた保護者向けに、保育園・こども園の「復職後の保護者負担」を検索・比較できるWebアプリケーションです。

既存の園検索サイトでは、所在地・定員・開園時間・延長保育の有無などの制度情報は確認できます。

しかし、実際に通わせるうえで重要な、

* 毎日の準備負担
* 平日に仕事を抜ける必要
* 延長保育を実際に利用している家庭の多さ
* 入園後、仕事と育児が無理なく回るか

といった情報は、見学や問い合わせをしないと分かりにくいことがあります。

ENKATSUでは、園そのものの良し悪しではなく、保護者が復職後に感じる負担に焦点を当てます。

口コミ投稿型のサービスではなく、構造化された比較項目をもとに、保護者が前向きに園選びを進められることを目指します。

# 3. どんな課題か

既存サイトでは制度情報は確認できても、

「入れる園」

は探せるが、

「復職後に生活が回る園」

は探しにくい。

特に、

* 毎日の家事負担
* 平日の時間負担
* 復職後の両立しやすさ

を比較する手段が少ない。

---

# 4. MVPで提供する価値

ENKATSUでは、

保育園を

* 生活負担
* 時間負担

の2軸で比較できるようにする。

---

## 生活負担

日々の準備や家事に関わる負担

比較項目

* 給食・弁当
* 持ち物負担
* おむつ対応
* 布団対応

表示方法

* 少ない
* 普通
* 多い

---

## 時間負担

仕事との両立に関わる負担

比較項目

* 延長保育利用者の多さ
* 平日行事
* 保護者会

表示方法

* 少ない
* 普通
* 多い

---

## 補助情報

メイン比較軸ではないが、園選びで参考になる情報

* 連絡帳
* 欠席連絡方法
* 園内習い事
* アレルギー対応

---

# 5. 新規性

既存サービスは、

* 所在地
* 定員
* 開園時間
* 延長保育の有無

などの制度情報比較が中心。

ENKATSUは、

* 生活負担
* 時間負担

という視点で比較する。

つまり、

「どの園に入れるか」

ではなく

「どの園なら復職後の生活が回るか」

を判断できるサービスである。

# 7. おすすめ順の方針

ENKATSUでは人気ランキングは実装しない。

おすすめ順は、

ユーザーが選択した条件と園情報の一致度によって決定する。

例

重視条件

* 延長保育利用者が多い
* 持ち物負担が少ない
* 平日行事が少ない
* 食事準備の負担が少ない

↓

条件に近い園ほど上位表示

# 13. MVPの一文まとめ

ENKATSUは、共働き家庭が園選びで見落としやすい「復職後の保護者負担」を、生活負担・時間負担という軸で検索・比較できるWebアプリです。

口コミや人気順ではなく、家庭ごとの条件に合うおすすめ順で園を提案することで、保護者が復職後の生活をイメージしながら園選びできることを目指します。
