# ENKATSU MVP案

## 〜園活を円滑に〜

## 1. サービス概要

ENKATSUは、共働き家庭・仕事復帰を控えた保護者向けに、保育園・こども園の「復職後の保護者負担」を検索・比較できるWebアプリケーションです。

既存の園検索サイトでは、所在地・定員・開園時間・延長保育の有無などの制度情報は確認できます。

しかし、実際に通わせるうえで重要な、

* 毎日の準備負担
* 平日に仕事を抜ける必要
* 延長保育を実際に利用している家庭の多さ
* 入園後、仕事と育児が無理なく回るか

といった情報は、見学や問い合わせをしないと分かりにくいことがあります。

ENKATSUでは、園そのものの良し悪しではなく、**保護者が復職後に感じる生活負担・時間負担**に焦点を当てます。

口コミ投稿型のサービスではなく、構造化された比較項目をもとに、保護者が前向きに園選びを進められることを目指します。

## 2. MVPで解決する課題

### だれの課題か

仕事復帰を控えた共働き家庭・保護者。

特に、復職後も仕事を継続しながら、日々の育児・家事・送迎を無理なく回したい保護者を主な対象とします。

## 3. ペルソナ

### メインペルソナ：キャリア継続型・タイパ最優先ママ

> 仕事はセーブしたくない。復職後も生活が回る園を、効率よく選びたい。

#### プロフィール

**佐藤 恵（31歳）**

* 職業・年収：IT企業のプロジェクトマネージャー。育休中で、今秋復職予定。年収600万円。
* 家族構成：夫（36歳・商社勤務・激務）、長男（0歳10ヶ月）。都内マンション在住。
* 性格・価値観：合理主義、タイムパフォーマンス重視。Excelやタスク管理ツールが得意。

#### 園活における状況と悩み

* 復職後は夫婦ともにフルタイム勤務予定。夫の出張も多く、平日はワンオペになる可能性が高い。
* 地域の保育園情報は多いが、「復職後に実際の生活が回るかどうか」が判断しづらい。
* 「何時に迎えに行けば、我が子が最後の一人にならないか」など、延長保育の実際の利用状況が分からない。
* 見学に行かないと、布団持ち帰り・おむつ対応・持ち物の多さなど、日々の名もなき家事負担が分からない。
* 平日の行事や保護者会で仕事を抜ける回数は、できるだけ事前に把握しておきたい。

#### ENKATSUが刺さる理由

* 「生活負担」「時間負担」という軸で、復職後に無理なく通える園を比較できる。
* 「延長保育の有無」ではなく、「延長保育を実際に利用している家庭が多いか」を確認できる。
* 給食・持ち物・おむつ・布団対応など、毎日の準備負担を事前に把握できる。
* 平日行事や保護者会の頻度を比較できるため、仕事への影響を想定しやすい。
* 復職前の限られた時間で、見学候補を効率よく絞り込める。

### サブペルソナ：両立重視・慎重派ママ

> 子どものケアは妥協したくない。でも、復職後の負担も増やしすぎたくない。

#### プロフィール

**高橋 美咲（34歳）**

* 職業・年収：メーカーの営業事務。育休中で、来春復職予定。年収380万円。
* 家族構成：夫（34歳・公務員）、長女（1歳2ヶ月・卵アレルギーあり）。郊外の一軒家在住。
* 性格・価値観：慎重派で心配性。SNSや口コミで育児情報を念入りに調べるタイプ。丁寧な暮らしに憧れるが、現実は余裕がない。

#### 園活における状況と悩み

* 子どもに軽度の卵アレルギーがあり、園でどこまで対応してもらえるのか不安がある。
* 園のHPには「アレルギー対応可能」としか書かれておらず、代替食が出るのか、家庭から弁当持参が必要なのか分からない。
* 復職後は時間に余裕がなくなるため、毎日の準備負担や平日の予定調整がどれくらい発生するか知りたい。
* 本当は習い事も検討したいが、平日の夕方や休日に追加で送迎する余裕はあまりない。
* 口コミサイトは主観的な情報やネガティブな書き込みが多く、何を信じてよいか分からず疲れている。

#### ENKATSUが刺さる理由

* 生活負担・時間負担を比較した上で、アレルギー対応や園内習い事などの補助情報も確認できる。
* 「完全除去のみ」「完全除去＋園で代替食」「完全除去＋家庭から弁当持参」など、構造化されたアレルギー対応情報を確認できる。
* 園内習い事の有無を見られるため、追加送迎の負担を減らせる可能性がある。
* 口コミではなく、比較しやすい項目として整理された情報を見られるため、判断疲れを減らせる。
* 子どものケアと保護者負担のバランスを見ながら、候補園を比較できる。

## 4. どんな課題か

既存サイトでは、制度上の情報は確認できても、実際に通わせる保護者の負担感や園の実態が分かりにくいという課題があります。

たとえば、以下のような情報は園公式サイトだけでは分かりにくく、見学や問い合わせをしないと確認しづらいです。

* 延長保育を実際に利用している子どもが多いか
* 持ち物や毎日の準備負担がどのくらいあるか
* 平日行事が多く、仕事を休む必要があるか
* 食事は毎日給食か、弁当の日があるか
* 保護者会や係活動の負担があるか
* おむつや布団の対応は家庭負担が大きいか

そのため、忙しい保護者が限られた時間の中で園見学・問い合わせ・情報収集を行う必要があり、園選びの負担や不安が大きくなっています。

## 5. MVPで提供する価値

ENKATSUでは、園の制度情報を網羅するのではなく、**復職後の保護者負担**に絞って比較できるようにします。

MVPでは、比較軸を以下の2つに整理します。

### 1. 生活負担

日々の準備や家事に関わる負担です。

例：

* 給食・弁当
* 持ち物負担
* おむつ対応
* 布団対応

### 2. 時間負担

仕事を抜ける必要や、お迎え時間に関わる負担です。

例：

* 延長保育利用者の多さ
* 平日行事の頻度
* 保護者会の頻度

特に「延長保育」は、単に有無を見るのではなく、**実際に延長保育を利用している家庭が多いかどうか**を重視します。

---

## 6. 補助情報として扱う項目

以下の情報は、メインの比較軸ではなく、園詳細ページやレポート内で確認できる補助情報として扱います。

* 連絡帳の形式
* 欠席連絡方法
* 園内習い事
* アレルギー対応

これにより、ENKATSUの軸を「保護者負担」に絞りつつ、こだわり条件を持つユーザーにも対応できる形にします。

---

## 7. 新規性

既存の園検索サイトは、所在地・定員・開園時間・延長保育の有無など、制度情報や基本情報の比較が中心です。

一方、ENKATSUは、制度の有無ではなく、**入園後に保護者の生活がどれくらい回りやすいか**に関わる情報を比較軸にします。

### 既存サービス

園を探すための情報を提供する。

例：

* 所在地
* 定員
* 開園時間
* 延長保育の有無
* 施設情報
* 園の特徴

### ENKATSU

入園後の生活を想像するための情報を提供する。

例：

* 毎日の準備負担
* 平日行事や保護者会による時間負担
* 延長保育を実際に使っている家庭の多さ
* 仕事と育児を両立しやすいか

つまり、ENKATSUの新規性は、

> 保育園を「施設情報」で比較するのではなく、働く保護者の「復職後負担」で比較すること

にあります。

* 布団対応

* 園種別
* 通わせやすさスコア

* 時間負担スコア

* 持ち物負担
* おむつ対応
* 布団対応
* 延長保育利用者の多さ
* 平日行事
* 保護者会
* 連絡帳
* 欠席連絡方法

* アレルギー対応

* 無料ユーザーは2園まで、プレミアムユーザーは3園比較可能にする

* 通わせやすさ
* 生活負担

* 無料プランとプレミアムプランを表示する
* プレミアムプランでは、詳細レポート閲覧・3園比較などを提供する

* Supabase Authを利用してログイン・会員登録を行う
* 未ログインでも園一覧・園詳細・2園までの一時比較は利用できる

### 7. マイページ

* ログイン済みユーザー専用画面として実装する
* 保存した比較リストを確認できる
* プレミアム状態を確認できる
* 詳細レポートへの導線を表示する
* ログアウトできる

MVPでは、プロフィール編集・お気に入り管理・請求履歴・プラン変更・解約機能は実装しない。

* プレミアムプラン購入用のCheckout Sessionを作成する
* Stripeの決済画面へ遷移する
* MVPでは月額500円のサブスクリプション課金を想定する

### 9. 決済完了画面

* 決済完了メッセージを表示する
* 詳細レポート画面へ遷移できる
* 比較画面に戻る導線を設置する

### 10. 詳細レポート画面

* 決済後に閲覧できるプレミアム機能
* 比較結果のまとめを表示する
* ユーザーの条件に合うおすすめ園を表示する
* 生活負担・時間負担の比較サマリーを表示する
* 見学時に確認したい質問リストを表示する
* 補助情報として、アレルギー対応・園内習い事・連絡帳・欠席連絡方法も表示する

## 9. おすすめ順の方針

MVPでは、人気順ランキングは実装しません。

ENKATSUでは、口コミ数や人気度ではなく、ユーザーが選択した条件と園情報の一致度をもとにした「おすすめ順」で園を表示します。

たとえば、ユーザーが以下の条件を重視した場合、

* 延長保育利用者が多い
* 持ち物負担が少ない
* 平日行事が少ない
* 食事準備の負担が少ない
* おむつ対応の負担が少ない
* 布団対応の負担が少ない

これらの条件に合う園を上位に表示します。

人気順ではなく、家庭ごとの条件に合う順にすることで、特定の園を一方的にランキング化するのではなく、保護者の状況に合わせた園選びを支援します。

## 10. ログイン・利用範囲の方針

ENKATSUでは、初回利用のハードルを下げるため、未ログインでも一部機能を利用できるようにします。

ユーザーは、まず登録なしで園一覧や園詳細を確認し、サービス価値を体験できます。

そのうえで、比較リストの保存やプレミアム機能を利用したいタイミングでログイン・会員登録に進む設計にします。

### 未ログインユーザー

* ホーム画面の閲覧
* 園一覧の閲覧
* 園詳細の閲覧
* 条件検索
* 2園までの一時比較

### ログイン済み無料ユーザー

* 園一覧の閲覧
* 園詳細の閲覧
* 条件検索
* 2園まで比較
* 比較リストの保存
* マイページで保存した比較リストを確認

### プレミアムユーザー

* 3園比較
* 詳細レポート閲覧
* 見学時に確認したい質問リスト
* 比較まとめコメント
* 比較結果の詳細確認
* マイページでプレミアム状態を確認

## 11. MVPでは実装しない機能

実質2週間で完成させるため、以下はMVP対象外とします。

* 口コミ投稿機能
* 口コミ承認機能
* 人気順ランキング
* AIによるレポート生成
* 地図表示
* 通知機能
* PDF出力
* 管理画面のフルCRUD
* お気に入り機能
* プロフィール編集
* 請求履歴表示
* アプリ内での解約・プラン変更
* 実在園データの大量登録
* 複雑なレコメンド機能

口コミ投稿・承認機能は、今後も慎重に扱う方針です。

マイナスな口コミが集まると園側の印象が悪くなり、情報提供をしてくれる園が減る可能性があるため、ENKATSUでは口コミ型サービスではなく、構造化された情報比較サービスとして設計します。

園データはMVPではseedデータとして登録し、管理画面からの登録・編集は後続機能とします。

## 12. 技術スタック

### Frontend

* Next.js
* TypeScript
* Tailwind CSS

スマホ利用を前提としたWebアプリ画面を実装します。

### Backend

* Express.js
* TypeScript

園情報、検索、比較、決済、レポート閲覧判定のAPIを実装します。

### Database

* Supabase Postgres

園情報、比較項目、決済状態、ユーザーのプレミアム状態、比較リストなどを管理します。

### ORM

* Prisma

Supabase Postgresに対するDB操作を型安全に行います。

### Auth

* Supabase Auth

ログイン・会員登録・ユーザー識別に利用します。

### Cache

* Redis

園一覧・検索結果をキャッシュし、同じ検索条件でのDBアクセスを減らします。

### Payment

* Stripe Checkout

月額プレミアムプランの決済に利用します。

### Validation

* Zod

検索条件やAPIリクエストの入力値を検証します。

### Security

* Helmet
* CORS設定
* Rate Limit
* Prisma Client
* XSSを意識した表示・入力制限

SQL Injection対策として、Prisma Clientを利用し、文字列結合によるSQLやunsafe raw queryは使わない方針にします。

### Logging

* Pino

開発環境と本番環境でログ出力を切り替えます。

### Test

* Vitest
* Supertest

検索条件、比較ロジック、課金判定、比較リスト保存、APIレスポンスなどに対して最小限の単体テスト・APIテストを実装します。

## 16. MVPのゴール

ENKATSUのMVPでは、以下の状態を目指します。

* スマホ前提のWebアプリとして操作できる
* 未ログインでも園一覧・園詳細・2園までの一時比較ができる
* ログイン済み無料ユーザーは比較リストを保存できる
* マイページで保存した比較リストを確認できる
* 園一覧を検索・絞り込みできる
* ユーザーの条件に合うおすすめ順で表示できる
* 園詳細で生活負担・時間負担・補助情報を確認できる
* プレミアムユーザーは最大3園を比較できる
* Stripe Checkoutで月額プレミアムプランを購入できる
* 決済後に詳細レポートを閲覧できる
* マイページでプレミアム状態を確認できる
* Redisで検索結果をキャッシュできる
* Zodで入力値検証ができている
* Pinoで開発環境と本番環境のログを出し分けられる
* 最小限の単体テスト・APIテストがある
* テスト設計書とREADMEがある

## 17. MVPの一文まとめ

ENKATSUは、共働き家庭が園選びで見落としやすい「復職後の保護者負担」を、生活負担・時間負担という軸で検索・比較できるWebアプリです。

口コミや人気順ではなく、家庭ごとの条件に合うおすすめ順で表示することで、保護者にも園にも前向きな形で園選びを支援します。

未ログインでも園情報を確認でき、価値を感じたタイミングでログイン・月額プレミアム登録へ進める設計にします。
