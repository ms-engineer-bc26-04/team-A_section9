# ENKATSU ブラッシュアップ版

## 【課題設定】

### だれの課題か

仕事復帰を控えた共働き家庭・保護者。

特に、復職後も仕事を継続しながら、日々の育児・家事・送迎を無理なく回したい保護者を主な対象とする。

### どんな課題か

既存の保育園検索サービスや自治体サイトでは、園の所在地・定員・保育時間・施設情報などは確認できる。

しかし、保護者が本当に知りたい

- 毎日の準備負担がどれくらいあるか
- 平日に仕事を抜ける必要がどれくらいあるか
- 延長保育を実際に利用している家庭が多いか
- 入園後、仕事と育児の両立が現実的に回るか

といった「復職後の保護者負担」は分かりにくい。

その結果、保護者は見学に行くまで実態が分からず、限られた育休期間の中で効率よく園を比較しづらい。

### どんなテクノロジーを使って解決するか

Webアプリとして、園ごとの情報を「生活負担」「時間負担」という軸で構造化し、検索・一覧・詳細・比較画面で可視化する。

使用予定技術：

- Next.js / TypeScript によるフロントエンド
- Express.js / TypeScript によるバックエンドAPI
- PostgreSQL / Prisma による園情報の管理
- Redis による検索・一覧データのキャッシュ
- Stripe による有料レポート決済
- Supabase Auth による認証
- Vitest / Supertest によるテスト

## 【課題解決】

ENKATSUは、保育園の基本情報を網羅するのではなく、保護者が復職後に困りやすい情報に絞って比較できるようにする。

主な比較軸は以下の2つ。

### 1. 生活負担

日々の準備や家事に関わる負担。

例：

- 給食・弁当
- 持ち物負担
- おむつ対応
- 布団対応

### 2. 時間負担

仕事を抜ける必要や、お迎え時間に関わる負担。

例：

- 延長保育利用者の多さ
- 平日行事の頻度
- 保護者会の頻度

特に延長保育については、「延長保育があるか」ではなく、「実際に利用している家庭が多いか」を表示する。

これにより、保護者は以下を判断しやすくなる。

- 復職後に毎日の準備が重くなりすぎないか
- 平日に仕事を抜ける機会が多すぎないか
- 自分の働き方に合った園か
- 見学前に候補園を効率よく絞れるか

また、園詳細や有料レポートでは、補助情報として以下も確認できる。

- 連絡帳の形式
- 欠席連絡方法
- 園内習い事
- アレルギー対応

そのため、メインターゲットである「復職後の負担を減らしたい保護者」だけでなく、「子どものケアや条件も確認したい保護者」にも対応できる。

## 【新規性】

既存サービスの多くは、保育園の所在地・定員・保育時間・施設情報など、園側の基本情報を掲載している。

一方ENKATSUは、園そのものの情報ではなく、**保護者が復職後にどれくらい負担を感じるか**に着目する。

### 既存サービス

園を探すための情報を提供する。

例：

- 所在地
- 定員
- 保育時間
- 施設情報
- 園の特徴

### ENKATSU

入園後の生活を想像するための情報を提供する。

例：

- 毎日の準備負担
- 平日行事や保護者会による時間負担
- 延長保育を実際に使っている家庭の多さ
- 仕事と育児を両立しやすいか

つまり、ENKATSUの新規性は、

> 保育園を「施設情報」で比較するのではなく、働く保護者の「復職後負担」で比較すること
> 

にある。

これにより、保護者は「入れる園を探す」だけでなく、「入園後に生活が回る園を選ぶ」ための判断ができるようになる。
