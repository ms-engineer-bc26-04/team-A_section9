# ENKATSU MVP案

## 〜園活を円滑に〜

## 1. サービス概要

ENKATSUは、共働き家庭・仕事復帰を控えた保護者向けに、保育園・こども園の「親の負担と実態情報」を検索・比較できるWebアプリケーションです。

既存の園検索サイトでは、開園時間や延長保育の有無などの制度情報は確認できますが、実際に通わせるうえで親の負担に直結する情報は分かりにくいことがあります。

ENKATSUでは、延長保育の実際の利用者の多さ、持ち物負担、平日行事、食事準備、保護者会、連絡帳、園内習い事、アレルギー対応などを園ごとに整理し、家庭に合う園を比較しやすくします。

口コミ投稿型のサービスではなく、園から提供された情報・公開情報・構造化された比較項目をもとに、保護者が前向きに園選びを進められることを目指します。

## 2. MVPで解決する課題

### だれの課題か

共働き家庭・仕事復帰を控えた保護者。

特に、仕事と育児を両立しながら、保育園・こども園を選ぶ必要がある保護者を対象にします。

### ペルソナ1：キャリア継続型・タイパ最優先ママ
「仕事は絶対にセーブしたくない。とにかく平日のタスクを減らし、仕組みで解決したい」という、最もENKATSUのコア価値が刺さるユーザー層です。

- 職業・年収： IT企業のプロジェクトマネージャー（育休中・今秋復職予定）。年収 600万円。  
- 家族構成： 夫（36歳・商社勤務・激務）、長男（0歳10ヶ月）。都内マンション在住。  
- 性格・価値観： 合理主義、タイムパフォーマンス（タイパ）重視。Excelやタスク管理ツールが得意。  

【園活における状況と悩み】  
- 状況： 復職後は夫婦ともにフルタイム。夫の出張も多いため、平日のワンオペ体制を想定して動いている。  
- 悩み：地域の保育園マップは見きれないほどあるが、「何時に迎えに行けば、我が子が最後の一人（寂しい思い）にならないか」という実態が見えない。見学に行かないと「手書き連絡帳」「布団シーツ毎週持ち帰り＆洗濯」といった名もなき家事負担が判明しないのがストレス。平日に園の行事や保護者会で仕事を抜けるのは、プロジェクト進行上できるだけ避けたい。

【ENKATSUが彼女に刺さる理由】  
- 「延長保育の利用者：多い」で絞り込める安心感
18:30に迎えに行っても、まだ他にもたくさん子どもが残っている園を見つけたい。  
- 「持ち物負担：少ない」「連絡帳：アプリ」の検索軸
布団レンタルあり、オムツ廃棄可、連絡帳アプリの園を即座に見つけて比較リストに入れたい。実家の支援が得られない彼女にとって、この項目は「死活問題」です。  
- プレミアムプランへの移行角度： 高（即決型）
復職前の貴重な時間を無駄な園見学で消費したくないため、「詳細レポート」や「見学時に確認したい質問リスト」を得るために迷わずStripe決済します。

### ペルソナ2：こだわり・心配性ママ（アレルギー・教育重視）
「負担は減らしたいけれど、子どものケアや教育の質は妥協したくない。でも自分のキャパシティも限界…」という、条件のトレードオフに悩むユーザー層です。

- 職業・年収： メーカーの営業事務（育休中・来春復職予定）。年収 380万円。  
- 家族構成： 夫（34歳：公務員）、長女（1歳2ヶ月・卵アレルギーあり）。郊外の一軒家在住。

【園活における状況と悩み】
- 状況： 子どもに軽度の卵アレルギーがある。初めての保活で、何から手をつけていいか不安。  
- 悩み：アレルギー対応について、園のHPには「対応可能」としか書かれておらず、「毎日お弁当持参なのか、園で代替食を出してくれるのか」が分からず不安。本当は習い事をさせたいが、平日の夕方や土曜日に送り迎えをする体力ルートが想像できない。園内で完結する習い事があれば最高だと思っている。口コミサイトを見ると、ネガティブな書き込み（感情的な批判）ばかりが目に入り、どこを信じていいか分からず疲弊している。  

【ENKATSUが彼女に刺さる理由】
- 口コミではない「構造化されたアレルギー対応」の情報  
「完全除去＋園での代替食提供」という客観的な事実ベースで絞り込めるため、精神的な不安が激減します。
- 園内習い事」の比較項目  
「体操」「英語」などが保育時間中に組み込まれている園を横並びで比較でき、復職後の「平日の習い事問題」が解決することに価値を感じます。  
- プレミアムプランへの移行角度： 中〜高（納得感重視）
最初は無料の2園比較を試しますが、アレルギー対応や習い事などのこだわり条件が多く、3園以上をじっくり横並びで精査したくなった段階でプレミアムプランに課金します。


### どんな課題か

既存サイトでは、制度上の情報は確認できても、実際に通わせる親の負担感や園の実態が分かりにくいという課題があります。

たとえば、以下のような情報は園公式サイトだけでは分かりにくく、見学や問い合わせをしないと確認しづらいです。

* 延長保育を実際に利用している子どもが多いか
* 持ち物や毎日の準備負担がどのくらいあるか
* 平日行事が多く、仕事を休む必要があるか
* 食事は毎日給食か、弁当の日があるか
* 保護者会や係活動の負担があるか
* 連絡帳はアプリか手書きか
* 園内習い事は何を実施しているか
* アレルギー対応はどの範囲まで行っているか

そのため、忙しい保護者が限られた時間の中で園見学・問い合わせ・情報収集を行う必要があり、園選びの負担や不安が大きくなっています。

## 3. MVPで提供する価値

ENKATSUでは、園の制度情報ではなく、親の負担と実態情報に絞って比較できるようにします。

ユーザーは、園一覧・検索・詳細・比較画面を通して、複数の園を横並びで確認できます。

特に、以下の項目を比較できることをMVPの中心価値とします。

* 延長保育の利用者：多い / 普通 / 少ない
* 持ち物負担：少ない / 普通 / 多い
* 平日行事：少ない / 普通 / 多い
* 食事準備：毎日給食 / 給食・弁当 / 毎日弁当
* 保護者会：なし / あり / 任意参加など
* 園内習い事：英語 / 体操 / リトミック / なし など
* 連絡帳：アプリ / 手書き / 併用
* アレルギー対応：

  * 完全除去のみ
  * 完全除去 + 園での代替食提供
  * 完全除去 + 家庭からの弁当持参

これにより、保護者は「制度として何があるか」だけではなく、「実際に通わせたときに親の負担がどのくらいあるか」を比較しながら園を選べます。

---

## 4. 新規性

既存の園検索サイトは、所在地・定員・開園時間・延長保育の有無など、制度情報や基本情報の比較が中心です。

一方、ENKATSUは、制度の有無ではなく、親の生活負担や園の実態に関わる情報を比較軸にします。

たとえば、延長保育は「制度があるか」ではなく「実際の利用者が多いか」、給食は「有無」ではなく「毎日給食か、弁当の日があるか」、連絡帳は「アプリか手書きか」といった形で、日々の負担に直結する情報を扱います。

また、口コミ投稿型ではなく、構造化された比較項目として情報を整理することで、園側にも情報提供してもらいやすく、保護者にも判断しやすい形で情報を届けます。

## 5. MVPで実装する機能

### 1. ホーム画面

* サービスの概要を表示する
* 「制度情報ではなく、親の負担と実態情報で比較できる」ことを伝える
* 園一覧画面への導線を設置する
* ENKATSUで比較できる項目を表示する

### 2. 園一覧・検索画面

* seedデータで登録した園情報を一覧表示する
* 条件検索・絞り込みを行う
* ユーザーの条件に合う「おすすめ順」で表示する
* 比較リストに追加できる

#### 検索・絞り込み項目

MVPでは、条件を増やしすぎず、以下を中心にします。

* エリア
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備

余裕があれば以下も追加します。

* 連絡帳
* 園内習い事
* アレルギー対応

### 3. 園詳細画面

* 園ごとの親の負担と実態情報を表示する
* 比較リストに追加できる

表示項目は以下です。

* 園名
* エリア / 住所
* 園種別
* 通わせやすさスコア
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備
* 保護者会
* 園内習い事
* 連絡帳
* アレルギー対応

### 4. 比較画面

* 最大3園まで横並びで比較する
* 制度の有無ではなく、親の負担・実態情報を比較する
* 無料ユーザーは2園まで、プレミアムユーザーは3園比較可能にする

比較項目は以下です。

* 通わせやすさ
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備
* 保護者会
* 園内習い事
* 連絡帳
* アレルギー対応

### 5. 料金・プラン画面

* 無料プランとプレミアムプランを表示する
* プレミアムプランでは、詳細レポート閲覧・3園比較などを提供する
* Stripe Checkoutへの導線を設置する

### 6. Stripe Checkoutへの遷移

* プレミアムプラン購入用のCheckout Sessionを作成する
* Stripeの決済画面へ遷移する

### 7. 決済完了画面

* 決済完了メッセージを表示する
* 詳細レポート画面へ遷移できる
* 比較画面に戻る導線を設置する

### 8. 詳細レポート画面

* 決済後に閲覧できるプレミアム機能
* 比較結果のまとめを表示する
* ユーザーの条件に合うおすすめ園を表示する
* 比較サマリーを表示する
* 見学時に確認したい質問リストを表示する

## 6. おすすめ順の方針

MVPでは、人気順ランキングは実装しません。

ENKATSUでは、口コミ数や人気度ではなく、ユーザーが選択した条件と園情報の一致度をもとにした「おすすめ順」で園を表示します。

たとえば、ユーザーが以下の条件を重視した場合、

* 延長保育の利用者が多い
* 持ち物負担が少ない
* 平日行事が少ない
* 食事準備の負担が少ない
* 連絡帳がアプリ
* アレルギー対応が手厚い

これらの条件に合う園を上位に表示します。

人気順ではなく、家庭ごとの条件に合う順にすることで、特定の園を一方的にランキング化するのではなく、保護者の状況に合わせた園選びを支援します。

## 7. MVPでは実装しない機能

実質2週間で完成させるため、以下はMVP対象外とします。

* 口コミ投稿機能
* 口コミ承認機能
* 人気順ランキング
* AIによるレポート生成
* 地図表示
* 通知機能
* PDF出力
* 管理画面のフルCRUD
* お気に入り機能
* マイページの本格実装
* 実在園データの大量登録
* サブスクリプション課金
* 複雑なレコメンド機能

口コミ投稿・承認機能は、今後も慎重に扱う方針です。
マイナスな口コミが集まると園側の印象が悪くなり、情報提供をしてくれる園が減る可能性があるため、ENKATSUでは口コミ型サービスではなく、構造化された情報比較サービスとして設計します。

園データはMVPではseedデータとして登録し、管理画面からの登録・編集は後続機能とします。

## 11. プレミアム機能

MVPでは買い切り型のプレミアムプランとします。

### 無料プラン

* 園一覧の閲覧
* 園詳細の閲覧
* 2園まで比較
* 一部の比較結果を確認

### プレミアムプラン

* 3園比較
* 詳細レポート閲覧
* 見学時に確認したい質問リスト
* 比較まとめコメント
* 比較結果の詳細確認

価格はMVPでは500円を想定します。
サブスクリプションではなく、1回購入の形式とします。

## 12. MVPのゴール

ENKATSUのMVPでは、以下の状態を目指します。

* スマホ前提のWebアプリとして操作できる
* 園一覧を検索・絞り込みできる
* ユーザーの条件に合うおすすめ順で表示できる
* 園詳細で親の負担と実態情報を確認できる
* 最大3園を比較できる
* Stripe Checkoutでプレミアムプランを購入できる
* 決済後に詳細レポートを閲覧できる
* Redisで検索結果をキャッシュできる
* Zodで入力値検証ができている
* Pinoで開発環境と本番環境のログを出し分けられる
* 最小限の単体テスト・APIテストがある
* テスト設計書とREADMEがある

## 13. MVPの一文まとめ

ENKATSUは、共働き家庭が園選びで知りたい「親の負担と実態情報」を、園ごとに検索・比較・詳細レポートとして確認できるWebアプリです。

口コミや人気順ではなく、家庭ごとの条件に合うおすすめ順で表示することで、保護者にも園にも前向きな形で園選びを支援します。
