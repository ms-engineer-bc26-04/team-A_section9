# ENKATSU MVP案

## 〜園活を円滑に〜

## 1. サービス概要

ENKATSUは、共働き家庭・仕事復帰を控えた保護者向けに、保育園・幼稚園の「親の負担と実態情報」を検索・比較できるWebアプリケーションです。

既存の園検索サイトでは、開園時間や延長保育の有無などの制度情報は確認できますが、実際に通わせるうえで親の負担に直結する情報は分かりにくいことがあります。

ENKATSUでは、延長保育の実際の利用者の多さ、持ち物負担、平日行事、食事準備、保護者会、連絡帳、園内習い事、アレルギー対応などを園ごとに整理し、家庭に合う園を比較しやすくします。

口コミ投稿型のサービスではなく、園から提供された情報・公開情報・構造化された比較項目をもとに、保護者が前向きに園選びを進められることを目指します。

---

## 2. MVPで解決する課題

### だれの課題か

共働き家庭・仕事復帰を控えた保護者。

特に、仕事と育児を両立しながら、保育園・幼稚園を選ぶ必要がある保護者を対象にします。

### どんな課題か

既存サイトでは、制度上の情報は確認できても、実際に通わせる親の負担感や園の実態が分かりにくいという課題があります。

たとえば、以下のような情報は園公式サイトだけでは分かりにくく、見学や問い合わせをしないと確認しづらいです。

* 延長保育を実際に利用している子どもが多いか
* 持ち物や毎日の準備負担がどのくらいあるか
* 平日行事が多く、仕事を休む必要があるか
* 食事は毎日給食か、弁当の日があるか
* 保護者会や係活動の負担があるか
* 連絡帳はアプリか手書きか
* 園内習い事は何を実施しているか
* アレルギー対応はどの範囲まで行っているか

そのため、忙しい保護者が限られた時間の中で園見学・問い合わせ・情報収集を行う必要があり、園選びの負担や不安が大きくなっています。

---

## 3. MVPで提供する価値

ENKATSUでは、園の制度情報ではなく、親の負担と実態情報に絞って比較できるようにします。

ユーザーは、園一覧・検索・詳細・比較画面を通して、複数の園を横並びで確認できます。

特に、以下の項目を比較できることをMVPの中心価値とします。

* 延長保育の利用者：多い / 普通 / 少ない
* 持ち物負担：少ない / 普通 / 多い
* 平日行事：少ない / 普通 / 多い
* 食事準備：毎日給食 / 給食・弁当 / 毎日弁当
* 保護者会：なし / あり / 任意参加など
* 園内習い事：英語 / 体操 / リトミック / なし など
* 連絡帳：アプリ / 手書き / 併用
* アレルギー対応：

  * 完全除去のみ
  * 完全除去 + 園での代替食提供
  * 完全除去 + 家庭からの弁当持参

これにより、保護者は「制度として何があるか」だけではなく、「実際に通わせたときに親の負担がどのくらいあるか」を比較しながら園を選べます。

---

## 4. 新規性

既存の園検索サイトは、所在地・定員・開園時間・延長保育の有無など、制度情報や基本情報の比較が中心です。

一方、ENKATSUは、制度の有無ではなく、親の生活負担や園の実態に関わる情報を比較軸にします。

たとえば、延長保育は「制度があるか」ではなく「実際の利用者が多いか」、給食は「有無」ではなく「毎日給食か、弁当の日があるか」、連絡帳は「アプリか手書きか」といった形で、日々の負担に直結する情報を扱います。

また、口コミ投稿型ではなく、構造化された比較項目として情報を整理することで、園側にも情報提供してもらいやすく、保護者にも判断しやすい形で情報を届けます。

## 5. MVPで実装する機能

### 1. ホーム画面

* サービスの概要を表示する
* 「制度情報ではなく、親の負担と実態情報で比較できる」ことを伝える
* 園一覧画面への導線を設置する
* ENKATSUで比較できる項目を表示する

### 2. 園一覧・検索画面

* seedデータで登録した園情報を一覧表示する
* 条件検索・絞り込みを行う
* ユーザーの条件に合う「おすすめ順」で表示する
* 比較リストに追加できる

#### 検索・絞り込み項目

MVPでは、条件を増やしすぎず、以下を中心にします。

* エリア
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備

余裕があれば以下も追加します。

* 連絡帳
* 園内習い事
* アレルギー対応

### 3. 園詳細画面

* 園ごとの親の負担と実態情報を表示する
* 比較リストに追加できる

表示項目は以下です。

* 園名
* エリア / 住所
* 園種別
* 通わせやすさスコア
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備
* 保護者会
* 園内習い事
* 連絡帳
* アレルギー対応

### 4. 比較画面

* 最大3園まで横並びで比較する
* 制度の有無ではなく、親の負担・実態情報を比較する
* 無料ユーザーは2園まで、プレミアムユーザーは3園比較可能にする

比較項目は以下です。

* 通わせやすさ
* 延長保育の利用者
* 持ち物負担
* 平日行事
* 食事準備
* 保護者会
* 園内習い事
* 連絡帳
* アレルギー対応

### 5. 料金・プラン画面

* 無料プランとプレミアムプランを表示する
* プレミアムプランでは、詳細レポート閲覧・3園比較などを提供する
* Stripe Checkoutへの導線を設置する

### 6. Stripe Checkoutへの遷移

* プレミアムプラン購入用のCheckout Sessionを作成する
* Stripeの決済画面へ遷移する

### 7. 決済完了画面

* 決済完了メッセージを表示する
* 詳細レポート画面へ遷移できる
* 比較画面に戻る導線を設置する

### 8. 詳細レポート画面

* 決済後に閲覧できるプレミアム機能
* 比較結果のまとめを表示する
* ユーザーの条件に合うおすすめ園を表示する
* 比較サマリーを表示する
* 見学時に確認したい質問リストを表示する

## 6. おすすめ順の方針

MVPでは、人気順ランキングは実装しません。

ENKATSUでは、口コミ数や人気度ではなく、ユーザーが選択した条件と園情報の一致度をもとにした「おすすめ順」で園を表示します。

たとえば、ユーザーが以下の条件を重視した場合、

* 延長保育の利用者が多い
* 持ち物負担が少ない
* 平日行事が少ない
* 食事準備の負担が少ない
* 連絡帳がアプリ
* アレルギー対応が手厚い

これらの条件に合う園を上位に表示します。

人気順ではなく、家庭ごとの条件に合う順にすることで、特定の園を一方的にランキング化するのではなく、保護者の状況に合わせた園選びを支援します。

---

## 7. MVPでは実装しない機能

実質2週間で完成させるため、以下はMVP対象外とします。

* 口コミ投稿機能
* 口コミ承認機能
* 人気順ランキング
* AIによるレポート生成
* 地図表示
* 通知機能
* PDF出力
* 管理画面のフルCRUD
* お気に入り機能
* マイページの本格実装
* 実在園データの大量登録
* サブスクリプション課金
* 複雑なレコメンド機能

口コミ投稿・承認機能は、今後も慎重に扱う方針です。
マイナスな口コミが集まると園側の印象が悪くなり、情報提供をしてくれる園が減る可能性があるため、ENKATSUでは口コミ型サービスではなく、構造化された情報比較サービスとして設計します。

園データはMVPではseedデータとして登録し、管理画面からの登録・編集は後続機能とします。

## 8. 技術スタック

### Frontend

* Next.js
* TypeScript
* Tailwind CSS

スマホ利用を前提としたWebアプリ画面を実装します。

### Backend

* Express.js
* TypeScript

園情報、検索、比較、決済、レポート閲覧判定のAPIを実装します。

### Database

* PostgreSQL
* Prisma

園情報、比較項目、決済状態などを管理します。

### Cache

* Redis

園一覧・検索結果をキャッシュし、同じ検索条件でのDBアクセスを減らします。

### Payment

* Stripe Checkout

プレミアムプラン購入機能を実装します。

### Validation

* Zod

検索条件やAPIリクエストの入力値を検証します。

### Security

* Helmet
* CORS設定
* Rate Limit
* Prisma Client
* XSSを意識した表示・入力制限

SQL Injection対策として、Prisma Clientを利用し、文字列結合によるSQLやunsafe raw queryは使わない方針にします。

### Logging

* Pino

開発環境と本番環境でログ出力を切り替えます。

### Test

* Vitest
* Supertest

検索条件、比較ロジック、課金判定、APIレスポンスなどに対して最小限の単体テスト・APIテストを実装します。

## 11. プレミアム機能

MVPでは買い切り型のプレミアムプランとします。

### 無料プラン

* 園一覧の閲覧
* 園詳細の閲覧
* 2園まで比較
* 一部の比較結果を確認

### プレミアムプラン

* 3園比較
* 詳細レポート閲覧
* 見学時に確認したい質問リスト
* 比較まとめコメント
* 比較結果の詳細確認

価格はMVPでは500円を想定します。
サブスクリプションではなく、1回購入の形式とします。

## 12. MVPのゴール

ENKATSUのMVPでは、以下の状態を目指します。

* スマホ前提のWebアプリとして操作できる
* 園一覧を検索・絞り込みできる
* ユーザーの条件に合うおすすめ順で表示できる
* 園詳細で親の負担と実態情報を確認できる
* 最大3園を比較できる
* Stripe Checkoutでプレミアムプランを購入できる
* 決済後に詳細レポートを閲覧できる
* Redisで検索結果をキャッシュできる
* Zodで入力値検証ができている
* Pinoで開発環境と本番環境のログを出し分けられる
* 最小限の単体テスト・APIテストがある
* テスト設計書とREADMEがある

---

## 13. MVPの一文まとめ

ENKATSUは、共働き家庭が園選びで知りたい「親の負担と実態情報」を、園ごとに検索・比較・詳細レポートとして確認できるWebアプリです。

口コミや人気順ではなく、家庭ごとの条件に合うおすすめ順で表示することで、保護者にも園にも前向きな形で園選びを支援します。
