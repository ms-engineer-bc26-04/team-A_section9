# ENKATSU 要件定義書

## 1. サービス概要

### サービス名

ENKATSU
〜園活を円滑に〜

### サービス概要

ENKATSUは、共働き家庭・仕事復帰を控えた保護者向けに、保育園・こども園の「復職後の保護者負担」を検索・比較できるWebアプリケーションです。

既存の園検索サービスでは、所在地・定員・開園時間・延長保育の有無などの制度情報は確認できます。

一方で、実際に通わせるうえで重要な、

* 毎日の準備負担
* 平日に仕事を抜ける必要
* 延長保育を実際に利用している家庭の多さ
* 入園後に仕事と育児が無理なく回るか
* 連絡帳や欠席連絡など、日々のやり取りのしやすさ

といった情報は分かりにくい課題があります。

ENKATSUでは、園そのものの良し悪しではなく、保護者が復職後に感じる「生活負担」「時間負担」に焦点を当てて比較できるようにします。

また、ログイン済みユーザーはお気に入り登録や比較機能を利用でき、プレミアムユーザーは3園比較・希望条件との一致表示・サポート情報の閲覧ができます。

---

## 2. 解決したい課題

### 課題

既存サービスでは「入れる園」は探せても、「復職後に生活が回る園」は探しにくいです。

保護者は、園見学や問い合わせをしないと、以下のような情報を把握しづらい状況があります。

* 給食か弁当か
* 持ち物負担が多いか
* おむつや布団の家庭負担があるか
* 延長保育を実際に利用している家庭が多いか
* 平日行事や保護者会が多いか
* 連絡帳や欠席連絡の方法
* 園内習い事やアレルギー対応の有無

その結果、復職前の限られた時間で園を比較する負担が大きくなっています。

### 解決方法

ENKATSUでは、園情報を以下の2軸で整理します。

* 生活負担
* 時間負担

さらに、園選びの補助情報として、連絡帳・欠席連絡方法・園内習い事・アレルギー対応などを表示します。

ログイン済みユーザーは希望条件を保存でき、保存した希望条件をホーム画面のおすすめ表示や、プレミアムユーザー向けの比較画面における一致項目ハイライトに利用します。

これにより、保護者が復職後の生活をイメージしながら、家庭に合う園を比較できるようにします。

## 3. ターゲットユーザー

### メインターゲット

仕事復帰を控えた共働き家庭・保護者。

特に、復職後も仕事を継続しながら、日々の育児・家事・送迎を無理なく回したい保護者を対象とします。

### サブターゲット

子どものケアや条件も確認しながら、保護者負担とのバランスを見て園を選びたい保護者。

---

## 4. 比較軸

### 4-1. 生活負担

日々の準備や家事に関わる負担です。

#### 比較項目

* 給食・弁当
* 持ち物負担
* 持ち物負担の具体的な内容
* おむつ対応
* 布団対応

#### 表示例

* 毎日給食
* 弁当あり
* 給食・弁当
* 持ち物負担：少なめ
* 持ち物負担の具体例：着替え・上履き程度
* おむつは園で廃棄
* おむつサブスク対応
* 布団は園で管理
* バスタオル持参

---

### 4-2. 時間負担

仕事との両立に関わる負担です。

#### 比較項目

* 延長保育利用時間
* 延長保育利用者の目安
* 平日行事の多さ
* 平日行事の具体的な内容
* 保護者会の負担
* 保護者会頻度

#### 表示例

* 延長保育利用時間：18:00〜20:00
* 延長保育利用者の目安：20人以上
* 平日行事：少なめ
* 平日行事の具体例：平日行事は少なめ
* 保護者会：少なめ
* 保護者会頻度：年に1回程度

延長保育については、制度の有無だけでなく、実際に利用している家庭がどの程度いるかを重視します。

---

### 4-3. サポート情報

生活負担・時間負担のメイン比較軸ではないものの、園選びの参考になる情報です。

#### 表示項目

* 連絡帳
* 欠席連絡方法
* 園内習い事
* アレルギー対応

#### 表示制限

未登録ユーザー・一般ユーザーには、サポート情報の項目名のみを表示し、内容はロック表示にします。

プレミアムユーザーは、サポート情報の内容まで閲覧できます。

## 5. 利用者区分

ENKATSUでは、利用者を以下の3区分で扱います。

| 区分        | 状態          | 内容                             |
| --------- | ----------- | ------------------------------ |
| 未登録ユーザー   | ログインしていない   | アカウント登録をしていない、またはログインしていないユーザー |
| 一般ユーザー    | ユーザー登録済み・無料 | Supabase Authで会員登録済みの無料ユーザー    |
| プレミアムユーザー | ユーザー登録済み・有料 | Stripe決済によりプレミアムプランが有効なユーザー    |

本ドキュメントでの「会員登録」は、無料のユーザー登録を指します。

プレミアムユーザーになるには、会員登録後にStripe Checkoutで決済を完了する必要があります。

アプリ内の会員区分は `users.plan_type` で補助的に管理し、実装上は `FREE` / `PAID` を使用します。

プレミアム判定は `subscriptions.status = ACTIVE` を正とします。

---

### 5-1. 未登録ユーザー

#### 利用可能

* ホーム閲覧
* 園一覧閲覧
* 園詳細閲覧
* 保育園名・住所検索
* 条件検索
* プラン・料金画面閲覧

#### 利用不可

* お気に入り登録
* お気に入り管理
* 比較機能
* マイページ利用
* プロフィール編集
* 希望条件の保存
* プレミアム機能利用
* サポート情報の内容閲覧

未登録ユーザーは、園情報を1件ずつ確認できます。

お気に入りボタンを押した場合は、ログイン誘導モーダルを表示します。

未登録ユーザーがプレミアム登録ボタンを押した場合は、まず会員登録画面 `/register` へ遷移します。

会員登録後は一般ユーザーとして扱い、その後Stripe Checkoutで決済を完了するとプレミアムユーザーになります。

---

### 5-2. 一般ユーザー

#### 利用可能

* 園一覧閲覧
* 園詳細閲覧
* 保育園名・住所検索
* 条件検索
* お気に入り登録
* お気に入り解除
* お気に入り一覧閲覧
* 2園比較
* マイページ利用
* プロフィール編集
* 希望条件の保存
* ログアウト

#### 制限

* お気に入り登録は5件まで
* 比較は2園まで
* サポート情報の内容は閲覧不可
* 希望条件との一致表示は利用不可
* 3園比較は利用不可

一般ユーザーは、園情報の閲覧、お気に入り登録、2園比較ができます。

ただし、お気に入り登録数は5件までとし、上限に達した場合はプレミアムプランへの誘導を表示します。

一般ユーザーも希望条件を保存できますが、比較画面での一致項目ハイライトはプレミアムユーザーのみ利用できます。

---

### 5-3. プレミアムユーザー

#### 利用可能

* 園一覧閲覧
* 園詳細閲覧
* 保育園名・住所検索
* 条件検索
* お気に入り登録
* お気に入り解除
* お気に入り一覧閲覧
* お気に入り無制限登録
* 3園比較
* 希望条件との一致表示
* サポート情報の内容閲覧
* マイページ利用
* プロフィール編集
* 希望条件の保存
* 一般プランへの変更導線
* ログアウト

プレミアムユーザーは、3つの園を同時に比較でき、プロフィール編集画面で設定した希望条件と一致する項目を比較画面で確認できます。

また、一般ユーザーではロックされているサポート情報の内容を閲覧できます。

## 6. 機能要件

### 6-1. ホーム画面

#### 対象

* 未登録ユーザー
* 一般ユーザー
* プレミアムユーザー

#### 機能

* サービス概要を表示する
* 保育園名・住所で検索できる
* 条件で検索できる
* 園一覧またはおすすめ園一覧を表示する
* 園詳細画面へ遷移できる
* お気に入り登録・解除ボタンを表示する

#### ログイン済みユーザー向けおすすめ表示

ログイン済みユーザーには、おすすめの園一覧を表示します。

おすすめ表示では、ユーザーの希望条件やお気に入り傾向をもとに表示します。

希望条件は、プロフィール編集画面から保存された `user_preferences` の情報を利用します。

MVPでは高度なレコメンド機能は作成せず、シンプルな条件一致数やお気に入り済み園の傾向をもとに並び替えます。

園一覧・検索結果・おすすめ表示では、Redisキャッシュを利用し、同一条件でのDBアクセスを減らします。

### 6-2. 園一覧・検索結果画面

#### 対象

* 未登録ユーザー
* 一般ユーザー
* プレミアムユーザー

#### 機能

* 園一覧を表示する
* 保育園名・住所で検索できる
* 条件検索ができる
* 検索条件を変更して再検索できる
* 園詳細画面へ遷移できる
* お気に入り登録・解除ができる

#### 検索条件

##### メイン検索

* 保育園名
* 住所
* エリア

##### 条件で検索

MVPでは、条件検索の「多い・少ない」はユーザーごとの主観ではなく、アプリ内の検索基準として定義します。

* 毎日給食
* おむつ園処理あり
* 布団負担少なめ
* 保護者会少なめ
* 延長保育利用者が多い
* 園内習い事あり
* アレルギー対応あり
* 平日行事少なめ

#### 条件検索の判定基準

| 画面表示       | バックエンド側の検索基準                   |
| ---------- | ------------------------------ |
| 毎日給食       | `mealType = SCHOOL_LUNCH`      |
| おむつ園処理あり   | `diaperSupport = "園で廃棄"`       |
| 布団負担少なめ    | `futonSupport = "園で管理"`        |
| 保護者会少なめ    | `parentAssociationLevel = LOW` |
| 延長保育利用者が多い | `extendedCareUsage = "20人以上"`  |
| 園内習い事あり    | `lessons IS NOT NULL`          |
| アレルギー対応あり  | `allergySupport IS NOT NULL`   |
| 平日行事少なめ    | `weekdayEventsLevel = LOW`     |

フロントエンドでは、チェックボックス条件について以下のようなquery paramsを送信します。

| 画面表示       | query params                 |
| ---------- | ---------------------------- |
| 毎日給食       | `mealType=SCHOOL_LUNCH`      |
| おむつ園処理あり   | `diaperSupport=true`         |
| 布団負担少なめ    | `futonSupport=true`          |
| 保護者会少なめ    | `parentAssociationLevel=LOW` |
| 延長保育利用者が多い | `extendedCareUsage=true`     |
| 園内習い事あり    | `lessons=true`               |
| アレルギー対応あり  | `allergySupport=true`        |
| 平日行事少なめ    | `weekdayEventsLevel=LOW`     |

バックエンド側で、`true` は検索基準に応じた値に変換して絞り込みます。

#### 表示項目

* 園名
* 住所
* エリア
* 園種別
* 特徴タグ
* お気に入りボタン

#### お気に入り制限

* 未登録ユーザー：利用不可。ログイン誘導モーダルを表示する
* 一般ユーザー：5件まで登録可能
* プレミアムユーザー：無制限で登録可能

一般ユーザーが5件登録済みの状態で追加登録しようとした場合は、上限メッセージを表示し、プレミアムプランへ誘導します。

### 6-6. ログイン / 会員登録

#### 機能

* 会員登録できる
* ログインできる
* ログアウトできる

#### 認証方式

Supabase Authを使用します。

#### 会員登録時の扱い

ENKATSUにおける会員登録は、無料のユーザー登録を指します。

会員登録後は、一般ユーザーとして扱います。

Supabase Authで会員登録した後、アプリ側の `users` テーブルにもユーザー情報を作成します。

MVPでは、ログイン後に `GET /users/me` を実行したタイミングで、Supabase Auth上のユーザーは存在するがアプリ側の `users` レコードが存在しない場合、バックエンド側で一般ユーザーとして自動作成します。

作成時の初期値は以下とします。

* `id`：アプリ内ユーザーIDとしてUUIDを自動生成
* `supabase_user_id`：Supabase Auth User ID
* `email`：Supabase Authのメールアドレス
* `plan_type`：`FREE`

プレミアムユーザーへの変更は、Stripe Checkout完了後、Webhookにより `subscriptions.status = ACTIVE` に更新された場合に行います。

* 保存後、マイページへ戻ることができる

#### 希望条件

ユーザーは、生活負担・時間負担に関する希望条件を設定できます。

##### 生活負担

* 毎日給食
* 持ち物負担が少ない
* おむつは園で処理してほしい
* 布団負担が少ない

##### 時間負担

* 延長保育を利用したい
* 平日行事が少ない
* 保護者会が少ない

#### 希望条件の保存先

希望条件は `user_preferences` テーブルに保存します。

1ユーザーにつき希望条件は0件または1件とし、未設定の場合は希望条件レコードを持たない状態とします。

希望条件が未設定の場合、APIでは `preference: null` を返します。

#### 希望条件の利用用途

保存した希望条件は、以下で利用します。

* ホーム画面のおすすめ表示
* プレミアムユーザーの比較画面における一致項目ハイライト

一般ユーザーも希望条件を保存できますが、比較画面での一致表示はプレミアムユーザーのみ利用できます。

### 6-10. Stripe Checkout

#### 機能

* プレミアムプラン購入用のCheckout Sessionを作成する

決済完了後は、ユーザーの会員状態をプレミアムとして扱います。

プレミアム判定は `subscriptions.status = ACTIVE` を正とします。

## 10. データ管理方針

MVPでは園データをseedで登録します。

#32 で検索・比較確認用に seed データを20件へ拡充しています。

### 園情報

* 園ID
* 園名
* エリア
* 住所
* 園種別
* 生活負担
* 時間負担
* 給食・弁当
* 持ち物負担
* 持ち物負担の具体的な内容
* おむつ対応
* 布団対応
* 延長保育利用時間
* 延長保育利用者の目安
* 平日行事の多さ
* 平日行事の具体的な内容
* 保護者会の負担
* 保護者会頻度
* 連絡帳
* 欠席連絡方法
* 園内習い事
* アレルギー対応
* 園の特徴・補足説明

### 条件検索で使用する園データの基準

MVPの条件検索では、以下の値を検索基準として使用します。

| 検索条件       | DB上の値・判定                         |
| ---------- | -------------------------------- |
| 毎日給食       | `meal_type = SCHOOL_LUNCH`       |
| おむつ園処理あり   | `diaper_support = "園で廃棄"`        |
| 布団負担少なめ    | `futon_support = "園で管理"`         |
| 保護者会少なめ    | `parent_association_level = LOW` |
| 延長保育利用者が多い | `extended_care_usage = "20人以上"`  |
| 園内習い事あり    | `lessons IS NOT NULL`            |
| アレルギー対応あり  | `allergy_support IS NOT NULL`    |
| 平日行事少なめ    | `weekday_events_level = LOW`     |

### seed データ登録時の注意

* `lessons` は、園内習い事がある場合のみ内容を登録する
* 園内習い事がない場合、`lessons` は NULL とする
* `lessons` には、年間行事・季節イベント・制作活動などは含めない
* `allergy_support` は、アレルギー対応がある場合のみ内容を登録する
* アレルギー対応がない場合、`allergy_support` は NULL とする
* `extended_care_usage` は、検索基準に合わせて `"20人以上"` / `"10〜20人程度"` / `"10人未満"` のように分類する
* `diaper_support` は、検索条件の「おむつ園処理あり」に該当する場合は `"園で廃棄"` と登録する
* `futon_support` は、検索条件の「布団負担少なめ」に該当する場合は `"園で管理"` と登録する
* 表示用テキスト項目は、比較画面・園詳細画面でそのまま読める文章として登録する

### ユーザー関連

* ユーザーID
* SupabaseユーザーID
* メールアドレス
* 会員区分
* 希望条件
* お気に入り園

### ユーザー希望条件

ユーザー希望条件は `user_preferences` テーブルで管理します。

1ユーザーにつき希望条件は0件または1件とします。

希望条件が未設定の場合、APIでは `preference: null` を返します。

保存する希望条件は以下です。

* 希望する給食・弁当区分
* 希望する持ち物負担レベル
* 希望するおむつ対応
* 希望する布団対応
* 希望する延長保育条件
* 希望する平日行事負担レベル
* 希望する保護者会負担レベル

保存した希望条件は、ホーム画面のおすすめ表示と、プレミアムユーザー向け比較画面の一致項目ハイライトで利用します。

### 決済関連

* Stripe Customer ID
* Stripe Subscription ID
* 決済状態
* 現在の課金期間終了日

### キャッシュ関連

MVPでは、園一覧・検索結果・おすすめ表示の高速化のため、Redisキャッシュを利用します。

キャッシュ対象は、主に以下とします。

* 園一覧
* 検索結果
* 条件検索結果
* おすすめ表示の元データ

ログインユーザーごとに変わるお気に入り状態・プレミアム状態・希望条件は、キャッシュされた園データとは分けて扱います。

## 12. MVPゴール

ENKATSUのMVPでは、以下の状態を目指します。

* 未登録ユーザーが園一覧を閲覧できる
* 未登録ユーザーが園詳細を閲覧できる
* 保育園名・住所・エリアで検索できる
* 条件検索できる
* 条件検索で、毎日給食・おむつ園処理あり・布団負担少なめ・保護者会少なめ・延長保育利用者が多い・園内習い事あり・アレルギー対応あり・平日行事少なめの条件で絞り込める

* 一般ユーザーが園を5件までお気に入り登録できる
* 一般ユーザーが2園比較できる
* 一般ユーザーが希望条件を保存できる
* 園詳細画面で、生活負担・時間負担・表示用テキスト項目を確認できる
* 比較画面で、持ち物負担の具体的な内容・平日行事の具体的な内容・保護者会頻度を比較できる
* プレミアムユーザーが園を無制限にお気に入り登録できる
* プレミアムユーザーが3園比較できる
* プレミアムユーザーが希望条件との一致表示を確認できる
* プレミアムユーザーがサポート情報を閲覧できる
* Stripeでプレミアム登録できる
* Stripe Webhookでプレミアム状態を更新できる
* マイページを利用できる
* Redisキャッシュを利用して園一覧・検索結果・おすすめ表示のDBアクセスを減らせる
* 最小限の単体テスト・APIテストがある
* READMEとテスト設計書がある

## 13. 一文要約

ENKATSUは、共働き家庭が園選びで見落としやすい「復職後の保護者負担」を、生活負担・時間負担という軸で検索・比較できるWebアプリケーションです。

未登録ユーザーは園情報を閲覧でき、一般ユーザーはお気に入り5件登録・2園比較・希望条件保存、プレミアムユーザーはお気に入り無制限・3園比較・希望条件との一致表示・サポート情報閲覧ができます。
