# 画面設計書：ENKATSU 〜園活を円滑に〜

## 1. 目的

本ドキュメントは、ENKATSU の画面構成・各画面の役割・表示項目・操作内容を整理し、チーム全員が同じ認識で実装を進められるようにするための画面設計書である。

ENKATSU は、共働き家庭・仕事復帰を控えた保護者向けに、保育園・こども園の「復職後の保護者負担」を生活負担・時間負担という2軸で検索・比較できる Web アプリケーションである。

未登録ユーザーは園情報を1件ずつ閲覧でき、一般ユーザーは2園比較、プレミアムユーザーは3園比較・チャート表示・お気に入り管理・詳細比較レポートの閲覧ができる。

## 3. 共通設計

### 3.1 共通レイアウト

**ホーム画面**

ホーム画面では、ENKATSU のサービス概要と導線を表示する。

```
Header（ロゴ・ログイン・会員登録ボタン）
↓
Hero Section（キャッチコピー・園一覧への CTA）
↓
比較軸の説明（生活負担・時間負担）
↓
おすすめ園への導線
↓
Footer
```

**未登録画面（ログイン・会員登録）**

認証フォームを中心に表示する。

```
App Title
↓
Auth Form
↓
ログイン / 会員登録 リンク
```

**一般ユーザー・プレミアムユーザー画面**

```
Header / Navigation
↓
Main Content
↓
Footer
```

Header には以下の導線を配置する。

| 項目       | 内容                                                     |
| ---------- | -------------------------------------------------------- |
| ロゴ       | `/` へ遷移する                                           |
| 園一覧     | `/parks` へ遷移する                                      |
| 比較リスト | `/compare/select` へ遷移する（バッジで選択中の件数表示） |
| マイページ | `/mypage` へ遷移する                                     |
| ログアウト | ログアウト処理を行う                                     |

未登録ユーザーの Header には「ログイン」「会員登録」ボタンを表示し、マイページ・比較リストは非表示とする。

### 3.2 共通 UI コンポーネント

| コンポーネント   | 用途                                           |
| ---------------- | ---------------------------------------------- |
| Button           | CTA・登録・削除・遷移などの操作ボタン          |
| Card（ParkCard） | 園一覧・比較リストでの園情報表示               |
| BurdenBadge      | 生活負担・時間負担の「少ない／普通／多い」表示 |
| CompareToggle    | 比較リストへの追加・削除ボタン                 |
| FavoriteButton   | お気に入り登録・解除ボタン（プレミアムのみ）   |
| SearchBar        | キーワード・条件検索の入力欄                   |
| FilterPanel      | 絞り込み条件のフォームパネル                   |
| Modal            | 確認ダイアログ・プレミアム誘導など             |
| Toast            | 操作フィードバック（成功・エラー・警告）       |
| Skeleton         | データ取得中のプレースホルダー                 |
| EmptyState       | データが存在しない場合の表示                   |
| ErrorMessage     | 入力エラー・API エラーの表示                   |
| Loading          | ページ・API 取得中のスピナー                   |
| LockOverlay      | 未登録・一般ユーザーへの機能制限表示           |

### 3.3 エラー表示方針

- 入力値に誤りがある場合は、フォーム項目の直下にエラーメッセージを表示する
- API 通信に失敗した場合は、画面上部または操作付近に Toast / エラーバナーを表示する
- 未登録ユーザーが認証必須画面にアクセスした場合は、`/login` へ遷移する
- 一般ユーザーがプレミアム限定画面にアクセスした場合は、`/plans` へ遷移する（またはモーダルで誘導する）
- 存在しない園 ID へアクセスした場合は、404 ページへ遷移する

### 3.4 ローディング表示方針

- API からデータ取得中は Skeleton コンポーネントを表示する
- ボタン操作中（送信・登録・削除）はボタン内スピナー + disabled 状態にして二重送信を防ぐ
- データが存在しない場合は EmptyState でメッセージを表示する

例：

```
お気に入りに登録した園はまだありません。
比較リストに追加した園はまだありません。
```

### 4.2 園一覧・検索画面

**URL**

`/parks`

**目的**

全ユーザーが条件検索・絞り込みで園を一覧表示し、詳細画面・比較リストへ進めるようにする。

**利用 API**

| メソッド | エンドポイント | 内容                                         |
| -------- | -------------- | -------------------------------------------- |
| GET      | `/parks`       | 園一覧・検索結果取得（Redis キャッシュあり） |

**検索・絞り込み条件**

| 条件                   | 内容               | 優先度           |
| ---------------------- | ------------------ | ---------------- |
| エリア                 | 地域で絞り込む     | MVP              |
| 延長保育利用者の多さ   | 少ない／普通／多い | MVP              |
| 持ち物負担             | 少ない／普通／多い | MVP              |
| 平日行事               | 少ない／普通／多い | MVP              |
| 食事準備（給食・弁当） | 給食のみ／弁当あり | MVP              |
| おむつ対応             | —                  | 余裕があれば追加 |
| 布団対応               | —                  | 余裕があれば追加 |
| アレルギー対応         | —                  | 余裕があれば追加 |

**表示項目（ParkCard）**

| 項目           | 内容                                           |
| -------------- | ---------------------------------------------- |
| 園名           | 園の名称                                       |
| エリア         | 所在地域                                       |
| 園種別         | 保育園・こども園など                           |
| 生活負担バッジ | 少ない／普通／多い                             |
| 時間負担バッジ | 少ない／普通／多い                             |
| 詳細ボタン     | `/parks/[id]` へ遷移する                       |
| CompareToggle  | 比較リストに追加・削除する                     |
| FavoriteButton | お気に入り登録・解除する（プレミアムのみ表示） |

**機能**

- 条件検索・絞り込みができる
- おすすめ順で表示できる
- 比較リストに追加できる（未登録ユーザーは利用不可、一般：2園まで、プレミアム：3園まで）
- プレミアムユーザーのみお気に入り登録・解除できる

**操作**

- 検索条件を入力・選択し、一覧を絞り込む
- ParkCard の詳細ボタンから `/parks/[id]` へ遷移する
- CompareToggle で比較リストに追加する（上限超過時は Toast で通知）
- 未登録ユーザーが CompareToggle をクリックした場合はログイン誘導モーダルを表示する

**空状態**

```
条件に合う園が見つかりませんでした。
検索条件を変えてお試しください。
```

**画面イメージ**

```

平日行事 [ select ]  食事準備 [ select ]
[ 検索する ]

エリア：△△区  種別：認可保育園
生活負担：[少ない]  時間負担：[普通]
```

### 4.4 比較リスト画面

**URL**

`/compare/select`

**目的**

ログイン済みユーザーが比較対象の園を確認・削除し、比較画面へ進めるようにする。

**利用 API**

| メソッド | エンドポイント | 内容                                                           |
| -------- | -------------- | -------------------------------------------------------------- |
| GET      | `/parks/:id`   | 選択済み園の情報取得（ローカルステートまたはセッションで管理） |

**表示項目**

| 項目             | 内容                                               |
| ---------------- | -------------------------------------------------- |
| 選択済み園カード | 園名・エリア・種別を表示する                       |
| 削除ボタン       | 比較リストから該当園を削除する                     |
| 比較するボタン   | 比較画面へ遷移する（2園未満は disabled）           |
| 追加の案内       | 選択件数と上限を表示する（例：「1 / 2 園選択中」） |

**制限**

| ユーザー区分       | 上限                        |
| ------------------ | --------------------------- |
| 未登録ユーザー     | 利用不可（`/login` へ遷移） |
| 一般ユーザー       | 2園まで                     |
| プレミアムユーザー | 3園まで                     |

**操作**

- 選択中の園を確認する
- 削除ボタンで園を比較リストから外す
- 「比較する」ボタンで `/compare` へ遷移する（選択数が 2 未満の場合は disabled）

**空状態**

```
比較したい園を一覧画面から選んでください。
[ 園を探す ]
```

**画面イメージ**

```
[比較リスト]  1 / 2 園選択中

┌────────────────┐  ┌────────────────┐
│ ○○保育園       │  │ ここに追加できます │
│ △△区 / 認可   │  │                │
│ [ 削除 ]       │  │                │
└────────────────┘  └────────────────┘

[ 比較する（2園選択で有効） ]
```

**対象ユーザー**

**表示項目**

| 項目                     | 内容                                            |
| ------------------------ | ----------------------------------------------- |
| おすすめ順位             | 1位・2位・3位のラベル表示（スコア数値は非表示） |
| 園名・エリア・種別       | 各園の基本情報                                  |
| 生活負担・時間負担バッジ | 各園の負担度合い                                |

## 6. 認証・認可による画面制御

| 画面                | 未登録ユーザー | 一般ユーザー                | プレミアムユーザー       |
| ------------------- | -------------- | --------------------------- | ------------------------ |
| `/`                 | ✅             | ✅                          | ✅                       |
| `/parks`            | ✅             | ✅                          | ✅                       |
| `/parks/[id]`       | ✅             | ✅                          | ✅                       |
| `/login`            | ✅             | リダイレクト（`/parks`）    | リダイレクト（`/parks`） |
| `/register`         | ✅             | リダイレクト（`/parks`）    | リダイレクト（`/parks`） |
| `/plans`            | ✅             | ✅                          | ✅                       |
| `/compare/select`   | ❌ → `/login`  | ✅（2園まで）               | ✅（3園まで）            |
| `/compare`          | ❌ → `/login`  | ✅（2園・チャートはロック） | ✅（3園・チャートあり）  |
| `/parks/recommend`  | ❌ → `/plans`  | ❌ → `/plans`               | ✅                       |
| `/report`           | ❌ → `/plans`  | ❌ → `/plans`               | ✅                       |
| `/mypage`           | ❌ → `/login`  | ✅（お気に入りなし）        | ✅（全機能）             |
| `/payment/complete` | ❌ → `/login`  | ✅                          | ✅                       |

**制御方針**

- 未ログインユーザーが認証必須画面へアクセスした場合は `/login` へ遷移する
- 一般ユーザーがプレミアム限定画面へアクセスした場合は `/plans` へ遷移する（またはモーダル誘導）
- 比較画面のプレミアム限定機能（チャート・3園目・レポート）は LockOverlay で制限し、`/plans` へ誘導する
- 画面側のルートガードに加え、バックエンド API 側でも必ず認可チェックを行う
- プレミアム判定は Stripe の決済状態（`subscription_status`）を利用する
- お気に入り機能（登録・解除・一覧）はプレミアムユーザーのみ利用できる
